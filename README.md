One funny fortune-cookie line for engineers, for the
[make.fun bounty "Fortune Cookie Funnies for Engineers"](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a).

## The entry

> You will inherit a codebase with no tests and one comment: 'good luck'. It was written by you.

94 characters — a single line, no padding. The fortune every engineer dreads:
the undocumented codebase waiting for you is your own past work.

## How it works

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, the file the house gate and judge read.
It refuses to write anything that breaks the gate (blank, over 140
characters, or more than one line).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
